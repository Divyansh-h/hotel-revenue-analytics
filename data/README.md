# Hotel Booking Revenue Analytics - Data Directory

This directory organizes data assets across raw, processed, and analytical output layers.

---

## 1. Source Dataset: `data/raw/hotel_bookings.csv`

The raw dataset (`hotel_bookings.csv`) is **not tracked in Git** (ignored via `.gitignore`) to comply with repository size and data governance standards.

### How to Download

1. **Primary Public Repository (Kaggle)**:
   - URL: [https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand](https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand)
   - Dataset: *Hotel booking demand* uploaded by Jesse Mostipak.
   - Download the file `hotel_bookings.csv` and place it directly into:
     ```
     data/raw/hotel_bookings.csv
     ```

2. **Original Scientific Source**:
   - António, N., de Almeida, A., & Nunes, L. (2019). *"Hotel booking demand datasets"*, **Data in Brief**, Volume 22, February 2019, pages 41–49.
   - DOI: [10.1016/j.dib.2018.11.126](https://doi.org/10.1016/j.dib.2018.11.126)

### Expected Verification
Before running the pipeline, verify the raw file with:
```bash
python src/verify_raw.py
```
- **Expected Dimensions**: Exactly **119,390 rows** and **32 columns**.
- **Properties**: City Hotel (Lisbon) and Resort Hotel (Algarve).
- **Date Range**: Arrivals from 2015-07-01 to 2017-08-31.
- **Rule R1**: The raw file is strictly read-only; never edit or overwrite it.

---

## 2. Processed Layer: `data/processed/`

Generated by `src/clean_data.py`:
- `bookings_clean.csv`: Cleaned analytical dataset containing 119,388 rows and 45 typed columns adhering to decisions D1–D12.
- `excluded_rows.csv`: 2 rows excluded per Decision D5 (`adr < 0` or `adr > 1000`) with documented audit reasons.

---

## 3. Output Marts: `data/outputs/`

Generated by PostgreSQL queries and exported via `src/export_sql_outputs.py`:
- `capacity.csv` & `capacity_derivation.csv`: Derived room inventory models (250 rooms City, 210 rooms Resort) per Rule W2.
- `daily_performance.csv`: 1,524 daily stay-night performance records across the 762-day reliable window.
- `v_monthly_kpis.csv` & `v_yearly_kpis.csv`: Monthly and annual stay-night KPIs (occupancy, ADR, RevPAR) adhering to K1–K4.
- `v_booking_trends.csv`: Booking pace and cancellation rates across 26 arrival months (K5, K6).
- `v_cancellation_drivers.csv`, `v_cancel_timing.csv`, `v_late_cancel_revenue_at_risk.csv`: In-depth cancellation dimension marts.
- `v_seasonality.csv`, `v_overbooking_buffer.csv`, `v_room_mismatch.csv`: Yield and inventory management views.
- `v_segment_performance.csv`, `v_channel_performance.csv`, `v_segment_channel_matrix.csv`: Commercial distribution metrics (K7).
